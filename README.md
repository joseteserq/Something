# Something

A tiny interactive idea generator for the repo named "Something".

## Run it

### Web Version

Open `index.html` in a browser, or serve the folder locally with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

### Terminal Version (Android Linux Terminal / Termux)

Run the bash script directly:

```bash
bash something.sh
```

Or make it executable and run it:

```bash
chmod +x something.sh
./something.sh
```

**Works on:**
- Termux (Android)
- Linux/macOS terminals
- Git Bash (Windows)
- Any POSIX-compatible shell

**Features:**
- Colorized terminal output
- Interactive menu
- No external dependencies
- Lightweight (~2KB)
